Ceci est une note d'exemple. Supprimez ce fichier une fois vos premières
notes exportées depuis AppFlowy ajoutées ici.

## Comment exporter depuis AppFlowy

1. Ouvrez la page à publier dans AppFlowy.
2. Menu `...` en haut à droite de la page → **Export** → **Markdown**.
3. Placez le fichier `.md` obtenu dans `src/content/docs/notes/`.
4. Ajoutez un bloc d'en-tête (`title`, `description`) en haut du fichier si absent.
